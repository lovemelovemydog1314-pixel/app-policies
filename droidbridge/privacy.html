应用处理的信息

应用通过 USB 直连或局域网协议在 Mac 与安卓设备之间传输文件。传输内容由两端设备直接收发，不经过任何开发者中转云服务器。

本机保存与权限

连接历史、安全书签与传输进度保存在 Mac 本机。钥匙串用于保存可选网络凭据，最近传输记录可随时手动清空。内购与订阅由 Apple StoreKit 安全处理。

DroidBridge 通过 USB（MTP/ADB）或本地局域网（FTP/WebDAV/网页快传）直接在 Mac 与安卓设备间传输。无开发者中转服务器，不经第三方云端。

你可以在应用提供的设置中清除相关历史或缓存；本机数据也可随卸载应用或移除其数据而删除。邮件支持内容仅在你主动发送后由支持团队收到。

DroidBridge 隐私政策

生效日期：2026 年 10 月 28 日

本政策适用于 macOS 版 DroidBridge（安卓桥）及其可选的 Android 配套工具。DroidBridge 是一款原生 macOS 菜单栏应用，专注于在 Mac 与 Android 设备之间进行高速文件浏览、传输与无线挂载。本政策说明应用在本机处理的信息、数据存储位置以及您的控制权。在 GitHub Pages 上托管的宣传或支持页面适用 GitHub 的相关服务政策。

本政策由 DroidBridge Team（DroidBridge 的开发者与维护者）发布。

1. 应用在本机与设备间处理的信息

文件与目录访问：应用仅访问您通过 macOS 文件选择器明确选取的本地目录、以及通过安全书签授权的同步文件夹。在安卓设备端，应用仅在设备解锁并授予 MTP、ADB 或 FTP/WebDAV 授权时，浏览与传输相应存储目录中的文件。所有文件均在 Mac 与设备两端直接收发，不经过任何开发者中转服务器或第三方云端存储。

相册与媒体直拖：菜单栏面板展示安卓设备相册最新的照片或截图缩略图，以便您直接拖拽至 Mac 应用中。MTP 模式下仅读取媒体缩略图，避免全量下载大文件；本地相册缓存严格限制在 300 MiB 上限以内，且可随时自动或手动清理。

传输历史与断点续传：为方便追踪传输状态与失败重试，应用在 Mac 本机保留最近完成、失败或取消的传输历史（最多 200 条），包括文件名、传输方向、文件大小、耗时与设备标识符。对于大文件传输中断，未完成数据保存在临时分片文件中，仅在校验通过后替换目标文件。您可在传输历史界面随时一键清空全部已完成记录。

剪贴板双向同步：仅在您主动启用剪贴板同步并扫描配对二维码后生效。配对使用动态 256 位会话令牌，传输内容在局域网内端对端加密。当伴侣 App 退至后台或设备断开连接时，同步会自动暂停。剪贴板数据仅驻留在设备内存中，不保存至磁盘，亦不上传云端。

2. 传输协议与网络安全

有线 USB 传输（MTP/ADB）完全在 Mac 与手机的本地物理总线或本地回环（127.0.0.1:5037）间完成，不产生任何外部互联网网络流量。

局域网传输（FTP/WebDAV/网页快传）：应用利用 Bonjour 广播仅在当前局域网内发现本地设备。扫码快传支持带证书指纹校验的 HTTPS 伴侣二维码，以及适用于无客户端环境的 HTTP 浏览器门户。因传统 FTP 和未配置证书的 HTTP 属于明文传输，请勿将传输端口映射至公共互联网，建议仅在受信任的私人 Wi-Fi 环境中使用。

3. 凭据、权限与本地存储

系统钥匙串（Keychain）：如果您选择保存连接 FTP 或 WebDAV 服务的密码凭据，该凭据将安全保存在 macOS 系统钥匙串中，享有系统级硬件加密保护，开发者无法接触。

沙盒与安全书签：应用遵循 macOS 严格的应用沙盒机制，仅通过系统标准安全范围书签（Security-Scoped Bookmark）持久化保存您选定的同步目录访问权限。

无广告与第三方分析：DroidBridge 不包含任何商业广告 SDK、第三方追踪器、数据统计或用户画像分析组件。

4. 内购与 StoreKit 处理

DroidBridge Pro 的购买、订阅与恢复均通过 Apple StoreKit 2 由 Apple 官方处理。交易与账单信息由 Apple 按照其隐私政策妥善处理，DroidBridge 不收集亦不存储任何支付卡号或财务信息。

5. 数据保留与彻底删除

连接历史、偏好设置和同步任务仅保存在您的 Mac 本地。您可以随时在应用设置与传输面板中清除传输历史与临时缓存；卸载应用并清理本地应用数据即可完全抹除。保存在钥匙串中的连接凭据可随时通过 macOS“钥匙串访问”手动移除。

6. 儿童隐私与政策变更

本应用不面向儿童收集任何个人信息，亦不设用户注册账号体系。若应用的功能更新涉及数据处理政策的调整，我们将在本页面更新生效日期并公示最新说明。

7. 联系支持

如果您对本隐私政策或数据处理有任何疑问，请联系我们：zipmaster_support@126.com。

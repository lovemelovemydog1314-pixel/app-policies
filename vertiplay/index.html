核心功能

VertiPlay 直连你的 Jellyfin、Emby、Plex 与 WebDAV / OpenList 服务器，带来单手极速竖刷、实时帧预览拖拽、跳过片头片尾、A-B 复读、离线缓存与面容 ID 隐私锁。

01

丝滑竖屏瀑布流与实时拖拽预览

1:1 跟手竖滑与双向播放器预加载消除黑屏卡顿；支持单指长按三档倍速、双指自由缩放平移及底部缩略图实时拖拽。

02

多协议私有媒体库直连

无需中转服务器，直连家庭 NAS 与远程节点；清晰展示硬件直放/转码路径，支持多服务端配置自动合并与媒体库隐藏控制。

03

跳过片头片尾与 A-B 区间复读

读取服务器 MediaSegments 与章节标记实现自动跳过片头片尾；支持精确 A-B 片段循环、画面旋转校正及外挂字幕样式调节。

04

离线缓存、投屏与面容 ID 隐私锁

支持离线下载至本机沙盒零流量观看、PiP 画中画、AirPlay 与服务器远程投放、16:9 全屏影院手势，以及 Face ID 后台隐私遮罩。

隐私摘要

VertiPlay 仅在你主动添加服务器后直连你的个人媒体库；密码与令牌保存在 iOS 系统钥匙串，无任何开发者后端服务器、账号体系或第三方统计追踪 SDK。

隐私摘要

VertiPlay 仅在你主动添加服务器后直连你的个人媒体库；密码与令牌保存在 iOS 系统钥匙串，无任何开发者后端服务器、账号体系或第三方统计追踪 SDK。

应用处理的信息

VertiPlay 仅在你主动添加服务器配置后，直接与你指定的 Jellyfin、Emby、Plex 或 WebDAV / OpenList 服务器通信以获取片源、海报、字幕与章节标记，并按你的操作同步收藏或播放进度。内置演示模式完全使用安装包内素材离线运行，不产生任何外部网络请求。

本机保存与权限

服务器访问令牌与密码安全保存于 iOS 钥匙串（Keychain）；服务器列表、搜索历史、画质与字幕偏好、离线下载视频及本地断点续播记录均保存在设备本地沙盒与 UserDefaults 中。本地网络权限用于连接局域网服务器与投屏；可选面容 ID 权限通过 Apple LocalAuthentication 保护应用隐私，生物特征数据绝不离开设备安全隔区。

网络与第三方服务

VertiPlay 仅在你添加服务器后直接连接你配置的 Jellyfin、Emby、Plex 或 WebDAV / OpenList 服务器。无自建中转云端、无开发者账号体系，不含任何第三方统计或广告追踪 SDK。

保留、删除与联系

你可以在应用提供的设置中清除相关历史或缓存；本机数据也可随卸载应用或移除其数据而删除。邮件支持内容仅在你主动发送后由支持团队收到。

VertiPlay（爱播）隐私政策

生效日期：2026 年 11 月 23 日

1. 适用范围与核心承诺

本隐私政策适用于 iOS 与 iPadOS 平台的 VertiPlay（简体中文名称：爱播）。VertiPlay 是一款面向私有媒体库用户的竖屏流媒体播放器。我们坚持“端侧直连、凭据隔离、零追踪分析”的隐私原则。

应用不设开发者账号系统，不运营任何用于采集、中转或分析用户观影数据的云端服务器，未集成任何第三方广告联盟、行为统计 SDK 或跨应用追踪（IDFA）。如有任何疑问，请通过邮件联系：zipmaster_support@126.com。

2. 处理的数据与功能边界

私有媒体服务器直连：仅在你主动添加服务器地址与凭据后，应用直接向你配置的 Jellyfin、Emby、Plex 或 WebDAV / OpenList 服务器发起请求，以拉取媒体目录、封面海报、视频流、音轨字幕、章节及片头片尾标记（MediaSegments），并在你操作点赞收藏、标为已看、添加播放列表或恢复播放进度时与你的自有服务器同步。

远程会话投放与 AirPlay：当你在局域网或当前服务器下选择投放至其他活跃客户端（/Sessions）或使用系统 AirPlay / 画中画（PiP）时，播放指令直接发送至目标播放设备或经由 Apple 系统框架处理，不经过开发者服务器中转。

内置离线演示模式：应用内置四段原创演示视频与海报（DemoAurora、DemoNeonCity、DemoEmber、DemoCinema）。在未配置任何服务器或处于断网状态时，演示模式完全读取应用安装包内本地资源运行，不产生任何网络流量。

3. 本机存储与凭据安全

iOS 钥匙串（Keychain）保护：你的媒体服务器密码与访问令牌（Token）仅保存于 iOS 系统钥匙串中，使用 kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly 保护属性，不会跨设备明文暴露或上传至开发者。

沙盒与偏好存储：服务器配置摘要、按服务器隔离的搜索历史、画质与字幕样式偏好、旋转记忆、本地播放列表与断点续播位置保存于设备本地 UserDefaults 与应用沙盒目录。离线下载缓存的视频文件保存在应用专属沙盒目录（VertiPlayOffline/），便于在无网环境下实现零流量播放。

4. 系统权限使用说明

本地网络权限（NSLocalNetworkUsageDescription）：用于连接同一局域网内搭建的 Jellyfin、Emby、Plex 或 WebDAV / OpenList 服务器，以及探索本地投放目标与 AirPlay 设备。

面容 ID 权限（NSFaceIDUsageDescription）：完全可选。仅当你在设置中主动开启“应用锁”时，应用调用 Apple LocalAuthentication 框架进行端侧身份解锁，并在切换至后台多任务视图时覆盖隐私遮罩。生物特征数据由系统安全隔区（Secure Enclave）处理，应用无法获取任何面容或指纹信息。

后台音频权限（UIBackgroundModes: audio）：用于在锁屏状态、画中画模式或切换应用时保持媒体音频播放，并配合系统 MediaPlayer 锁屏控制中心展示当前播放信息。

5. 数据保留、清理与用户控制

你可以随时在应用“设置 → 缓存管理”中查看离线缓存占用空间、配置缓存大小与保留天数上限、删除单个或全部离线缓存视频，或在搜索栏清理近期搜索历史。移除服务器配置或直接卸载 VertiPlay 应用将清除所有本地沙盒数据及对应的钥匙串凭据。

6. 儿童隐私、政策更新与联系我们

VertiPlay 不会故意收集 13 岁（或当地适用法律规定年龄）以下儿童的个人信息。若本隐私政策发生修订，我们将在本页面更新内容与生效日期。

支持邮箱：zipmaster_support@126.com（来信时请附带应用版本、iOS 版本与问题说明，切勿发送你的服务器密码或访问令牌）。

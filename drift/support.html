技术支持与常见问题 (Support & FAQ)

遇到使用问题或有改进建议？在此快速找到解答，或与我们的开发团队联系。

Q1: 为什么首次启动需要我授权访问文件夹？

Drift 严格遵守苹果官方的 macOS App Sandbox（应用沙盒） 安全机制。在沙盒模式下，任何应用在未获得您显式授权前，均被物理隔离无法读取磁盘内容。您只需在首次启动时点击一次“授权并扫描”，后续应用即可通过加密的安全范围书签（Security-Scoped Bookmarks）记住该权限，无需每次重复授权。

Q2: 清理文件安全吗？如果不小心点错能否恢复？

绝对安全。 Drift 恪守安全底线，所有清理操作均调用 macOS 原生系统接口，将选中的项目移入系统废纸篓（Trash），绝不会执行不可逆的物理粉碎。如果您发现误选了文件，直接在 Mac 废纸篓中右键点击“放回原处”即可瞬间复原。

Q3: 重复文件排查（Duplicate Finder）是如何判断文件重复的？

Drift 采用银行级的多级哈希内容指纹算法：首先按精确物理字节大小分组，接着校验文件头尾数据块特征，最后使用 Apple CryptoKit 进行全文 SHA-256 内容哈希 比对。只有当内容指纹完全一致时才被判定为副本，无论文件名或修改日期是否相同，100% 杜绝误报。

Q4: 什么是“完全磁盘访问权限（Full Disk Access）”？我需要开启吗？

默认情况下，即使授权了个人目录，macOS 也会对部分敏感系统文件夹（如邮件附件、信息历史、Safari 缓存等）进行额外拦截。如果您在扫描结果中看到“由于权限原因部分项目被跳过”，建议根据应用内指引开启系统的“完全磁盘访问权限”，即可解锁无死角的全局精准空间洞察。

Q5: 清理“开发者建议”中的 DerivedData 或 node_modules 会影响项目吗？

不会损坏项目源码。DerivedData 是 Xcode 的索引与中间编译产物，清除后仅在下次编译时重新生成索引；node_modules 是前端 npm/yarn/pnpm 的依赖包，可随时通过 npm install 重新下载。Drift 明确区分了“可安全重建”与“建议核对”级别，助您安心释放大量磁盘空间。

Q6: 为什么有些文件显示物理大小与逻辑大小不同？

macOS 的 APFS 文件系统支持“写时复制克隆（Copy-on-Write Clones）”与稀疏文件，多个文件可能共享同一块底层磁盘扇区；此外，iCloud 云端文件在未下载到本地时仅占有占位符体积。Drift 能精准分辨“物理占用”与“名义大小”，避免虚假统计。
